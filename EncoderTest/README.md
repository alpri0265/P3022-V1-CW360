# Тестовий скетч для перевірки енкодера

Цей тестовий скетч допомагає визначити реальну поведінку енкодера.

## Як використовувати:

1. **Відкрийте цю папку як окремий проект в Arduino IDE:**
   - File → Open → виберіть файл `EncoderTest.ino` з цієї папки

2. **Завантажте скетч на Arduino Micro**

3. **Відкрийте Serial Monitor:**
   - Швидкість: 115200 baud
   - Відображення: Newline

4. **Обертайте енкодер і спостерігайте за виводом:**
   - Зверніть увагу на значення `counter` - воно показує загальну кількість кроків
   - При одному фізичному кліку енкодера дивіться, на скільки змінюється `counter`
   - Це допоможе визначити, скільки імпульсів генерує енкодер на один клік

## Що шукати:

- **Значення delta** при одному кліку енкодера (наприклад, якщо counter змінюється на 4, 8, 16 тощо)
- **Частота спрацювання `turn()`** - скільки разів вона спрацьовує на один клік
- **Значення `clicks`** в EncButton - це може відрізнятися від нашої реалізації

## Після тестування:

Повідомте, яке значення delta (кількість кроків) ви отримуєте на один фізичний клік енкодера. Це допоможе виправити логіку в основному проекті.
